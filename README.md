# Trestle（栈架）

> 工匠支起案板、摆放图纸与校核量具的栈架：承托任务脉络、交接简报与验证回执，而不侵入外部业务源码仓库。

**Trestle（栈架）** 是一个本地优先、与具体业务领域无关的通用个人工作台工具（Rust 实现，命令行入口 `wb`）。

- **命令入口**：`wb`（单一静态编译可执行文件，构建产物 `target/release/wb` 或 `target/debug/wb`）
- **最小依赖**：纯 Rust 实现（无 Python / Node.js 运行时依赖；`Git` 为可选工具，未安装时仍可正常进行任务管理与本地看板浏览）
- **核心边界**：工作台目录与外部代码仓库目录严格分离，只保存任务登记、时间顺序进展、交付声明、验证回执与方案材料，不复制业务源码；本地网页看板完全只读并仅绑定 `127.0.0.1`。

## 构建与测试

```bash
cargo build --offline
cargo test --offline
```
